## Marketing Copy Rules

- **Clarity > clever.** Jelas lebih penting dari keren.
- **Tulis untuk manusia, bukan AI.** Gak ada filler, gak ada template "Dengan X, Anda dapat Y sehingga Z".
- **1-3 poin utama.** Sisanya buang. Lebih sedikit = lebih kuat.
- **Setiap kalimat harus jawab "terus kenapa?"** dari sudut pandang pembaca.
- **Review:** kalau bisa dihapus tanpa kehilangan makna → hapus.
- **Jangan sebut kompetitor** kecuali Hafish minta.
- **Flow LP:** Hero → Problem → Comparison/proof → How → CTA. Gak lebih.
